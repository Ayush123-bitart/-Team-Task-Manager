# 📋 TaskFlow - Team Task Manager

A full-stack web application for teams to create, assign, and track tasks in real-time. Simplifies project management and improves team collaboration with a clean Kanban-style dashboard.

## ✨ Key Features
- **User Authentication**: Secure login/signup with JWT
- **Project Boards**: Create multiple projects and invite team members
- **Task Management**: Create, assign, update status: To-Do, In Progress, Done
- **Real-time Updates**: Instant task updates across all team members
- **Dashboard Analytics**: Track project progress and team productivity
- **Role-Based Access**: Admin, Manager, Member roles with different permissions

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT, bcrypt
- **Deployment**: Vercel + Render
